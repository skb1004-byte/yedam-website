홈 선생님도우미 생기부·평어 도우미

처음 오셨나요? 5분이면 충분합니다

선생님도우미는 생기부·평어·세특 작성, 학생 검사 결과 활용, NEIS 시간표 조회까지 담임 업무를 돕는 무료 도구 모음입니다. 설치나 로그인 없이 브라우저에서 바로 쓸 수 있고, 입력한 학생 정보는 서버로 전송되지 않고 선생님 컴퓨터(브라우저)에만 저장됩니다.

선생님도우미 허브에서 아래 도구로 이동할 수 있습니다.

그림 1. 선생님도우미 전체 구성도

1생기부 문장 — 강점 키워드로 초안 만들기

관찰한 강점 키워드 몇 개만 고르면 행동특성·자율·진로·동아리 특기사항 초안을 개조식으로 만들어 줍니다.

그림 2. 생기부 문장 생성 3단계
  1. 영역을 고릅니다 — 행동특성 및 종합의견 / 자율·자치 / 진로 / 동아리. 영역에 따라 권장 글자수(500자 또는 700자)가 자동 적용됩니다.
  2. 강점 키워드를 여러 개 클릭합니다(초록색으로 켜짐). 목록에 없는 특징은 자유 키워드 칸에 쉼표로 적으면 됩니다. 예: 학급 게시판 관리, 모둠 발표 주도
  3. 학생 이름은 선택 사항입니다. 비우면 이름 없이 생성됩니다.
  4. 문장 생성을 누르면 결과 칸에 초안이 나타납니다. 마음에 들지 않으면 다시 생성 — 누를 때마다 다른 조합의 문장이 나옵니다.
  5. 결과 칸에서 직접 고쳐 쓴 뒤 복사를 눌러 나이스에 붙여넣습니다.
글자수·byte 자동 계산: 결과 아래에 글자수와 NEIS 기준 byte가 실시간 표시되고, 권장 상한을 넘으면 빨간색으로 경고합니다. 나이스는 한글 1자를 3byte로 계산하는데 이 규칙 그대로 계산해 드립니다.
검사 결과 자동 불러오기: 학생이 AI PIA 검사를 마친 뒤 결과지에서 "선생님도우미로 보내기"를 누르면, 이 화면을 열 때 강점 키워드가 자동으로 선택돼 있습니다(24시간 이내, 같은 컴퓨터).

2교과 평어 — 반 전체를 한 번에, 전혀 겹치지 않게

과목·성취수준·명단만 넣으면 학생마다 서로 다른 평어를 배정합니다. 같은 문장이 두 학생에게 나가지 않습니다.

  1. 학년·과목·성취수준을 고릅니다. 학년은 저장되어 다음에 자동으로 불러옵니다.
  2. 🔎 단원·영역 자동을 누르면 2022 개정 교육과정 기준 그 과목의 영역이 추천 단추로 나타납니다. 여러 개를 클릭하면 클릭한 것이 모두 입력칸에 쉼표로 담기고, 다시 클릭하면 해제됩니다. 학기(1·2학기)에 맞춰 순서도 바뀝니다.
  3. 명단은 한 줄에 한 명씩 입력합니다. 인원수를 넣고 # 번호로 채우기를 누르면 1번~N번으로, 🎲 랜덤 이름은 연습용 가짜 이름으로 채워 줍니다. 명단 저장을 해 두면 다음에 명단 불러오기로 재사용할 수 있습니다.
  4. 생성 범위에서 "이 과목만" 또는 "전 과목 일괄 생성"을 고르고 학급 평어 생성을 누릅니다.
  5. 표에서 학생별 복사는 평어 문장만 복사합니다(나이스 특기사항 칸에 바로 붙여넣기). 📋 전체 복사는 이름·과목·평어를 탭으로 구분한 표 형식이라 나이스 그리드나 엑셀에 한 번에 붙습니다.
그림 3. 같은 성취수준이라도 학생마다 단원·문형이 다르게 배정됩니다
무중복 원리: 기본 문장 × 단원·영역 × 서두 표현을 조합해 수십~수백 가지 서로 다른 문장을 만들고, 학생마다 겹치지 않게 하나씩 배정합니다. 40명 학급도 전원이 다른 평어를 받습니다.

3수행평가 피드백 — 점수만 넣으면 수준 판정 + 문장까지

점수를 입력하면 성취수준(매우 잘함~노력 요함)을 자동 판정하고 학생마다 다른 피드백 문장을 붙여 줍니다.

  1. 과목을 고르고, 평가 과제·영역명은 직접 입력하거나 🔎 단원·영역 자동으로 교육과정 영역을 클릭해 채웁니다(여러 개 선택 가능).
  2. 점수 → 수준 기준을 학교 기준에 맞게 조정합니다. 기본값은 90/75/60입니다.
  3. 명단을 채우고 표 만들기 · 점수 입력을 누릅니다. 평어 명단 가져오기를 누르면 ② 탭 명단을 그대로 씁니다.
  4. 표의 점수 칸에 점수를 입력하는 즉시 수준과 피드백 문장이 바뀝니다. 이때도 다른 학생과 겹치지 않는 문장이 배정됩니다.
  5. 문장 다시 배정은 점수는 그대로 두고 문장만 새로 뽑습니다. 📋 전체 복사는 이름·점수·피드백을 표 형식으로 복사합니다.
점수를 입력하지 않은 학생은 문장이 비어 있습니다. 인쇄 전에 점수 누락을 확인하세요.

과목별 단원·영역 예시 (직접 눌러 보세요)

과목 단추를 누르면 그 과목에서 "🔎 단원·영역 자동" 추천으로 나오는 예시가 보입니다. ② 교과 평어 · ③ 수행평가 · ④ 교과 세특 탭에서 똑같이 사용됩니다.

4교과 세특 — 세부능력 및 특기사항 2~4문장

과목·성취수준·단원을 정하면 학생마다 전혀 겹치지 않는 세특을 만들어 줍니다. [수업 성취] + [관찰 모습] + [성장 전망] 구조입니다.

그림 4. 세특 문장 구조 — 조합이 달라 학생끼리 겹치지 않습니다
  1. 과목·성취수준·분량(간단 2문장 / 표준 3문장 / 자세히 4문장)을 고릅니다.
  2. 단원·영역 키워드를 직접 쓰거나 🔎 단원·영역 자동에서 여러 개 클릭해 담습니다.
  3. 명단을 채우고(평어 명단 가져오기 지원) 세특 생성을 누릅니다.
  4. 표에 학생별 세특과 글자수·byte가 함께 표시됩니다. 개별 복사 또는 📋 전체 복사(이름·세특 표 형식)로 나이스에 옮깁니다.
생성 문구는 초안입니다. 실제 관찰 근거에 맞게 반드시 검토·수정한 뒤 입력하시고, 해당 학년도 기재요령과 분량 기준을 확인하세요.

5검사 실행 · 결과지(교사용)

학생이 AI PIA 통합검사를 마치면 교사용 결과지를 확인하고, 강점 키워드를 생기부 도우미로 바로 넘길 수 있습니다.

  1. 선생님도우미 허브에서 검사 실행 · 결과지(교사용) 카드를 누르면 바로 통합 결과 화면으로 이동합니다.
  2. 결과지 표지의 성명·학교·학년/반·검사일·발급일·담당기관(학생의 학교명)은 검사 정보에서 자동으로 채워집니다.
  3. 결과지 보기 탭에서 학생 본인용 / 학부모·선생님용을 전환할 수 있고, 인쇄·HTML 저장·TXT 저장·복사를 지원합니다.
  4. 결과 화면의 "선생님도우미로 보내기" 단추를 누르면 강점 키워드가 저장되고, 생기부·평어 도우미의 ① 생기부 문장 탭을 열면 해당 키워드가 자동 선택돼 있습니다.
그림 5. 검사 결과 → 생기부 키워드 자동 전달 흐름
전달 조건: 같은 컴퓨터·같은 브라우저에서 24시간 이내에 열어야 하며, 한 번 불러오면 자동으로 지워져 중복 입력을 막습니다.

6NEIS 시간표 · 학사일정

학교 이름만 넣으면 나이스 공공 API에서 이번 주 시간표와 학사일정을 불러옵니다.

  1. 학교명을 입력하고 검색합니다. 같은 이름의 학교가 여러 곳이면 지역으로 구분해 고릅니다.
  2. 학년·반을 고르면 이번 주 시간표가 표로 나타납니다.
  3. 학사일정에는 공휴일·재량휴업·방학·행사가 배지로 구분되어 표시됩니다.
  4. 생기부 문장 생성기(나이스 입력 도우미)에서는 NEIS 과목·시수 자동 단추로 이번 주 시간표를 읽어 과목·주당 시수를 자동으로 채울 수 있습니다.
학기 초·방학 중에는 나이스에 시간표 자료가 아직 없어 "데이터가 없습니다"라고 나올 수 있습니다. 이 경우 잠시 후 다시 시도하거나 직접 입력하세요. 학생·교사 이름은 나이스 공공 API가 제공하지 않는 정보라 불러올 수 없습니다.

7자주 묻는 질문

질문답변
학생 이름 등 개인정보가 외부로 나가나요?아니요. 명단·평어·세특은 모두 선생님 브라우저 안에서만 만들어지고 저장(localStorage)됩니다. 서버로 전송되지 않으며 AI 모델 학습에도 사용되지 않습니다.
저장한 명단이 사라졌어요.브라우저 방문기록(사이트 데이터)을 삭제하면 저장된 명단·학년 설정도 함께 지워집니다. 다른 컴퓨터에서는 저장 내용이 공유되지 않습니다.
인쇄 버튼을 눌러도 반응이 없어요.브라우저가 팝업을 차단한 경우입니다. 주소창의 팝업 차단 안내를 눌러 "허용"으로 바꾼 뒤 다시 시도하세요.
전체 복사가 나이스에 이상하게 붙어요.전체 복사는 탭 구분 표 형식입니다. 나이스 그리드나 엑셀에는 한 번에 붙지만, 일반 텍스트 칸에는 학생별 개별 복사를 사용하세요.
생성된 문장을 그대로 써도 되나요?초안으로만 사용하세요. 교육부는 생성형 도구를 생기부 작성의 보조수단으로 허용하고 있지만, 최종 문장은 교사의 실제 관찰 근거로 검토·수정해야 합니다.
단축키가 있나요?모든 입력칸은 Tab으로 이동, 결과 텍스트는 Ctrl+A → Ctrl+C로 복사할 수 있습니다.
