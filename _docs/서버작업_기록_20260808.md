## 겪은 문제 네 가지

### 🔴 결과 API 를 몇 분간 죽였다 (내 실수)

자동 기동을 등록하면서 `Get-Process node | Stop-Process -Force` 를 돌렸다.
결과 API 도 node 로 돌기 때문에 **그것까지 같이 꺼졌다.**
확인 과정에서 발견해 `Start-ScheduledTask` 로 되살렸다.
프로세스를 이름으로 싸잡아 끄면 안 된다. 작업 스케줄러 단위로 다뤘어야 했다.

### `Restart-ScheduledTask` 가 없다

이 환경에는 그 명령이 없다. `Stop-ScheduledTask` → `Start-ScheduledTask` 로 갈랐다.

### 작업 스케줄러의 `-Execute 'node'` 가 안 뜬다

SYSTEM 계정 PATH 에 node 가 없다. 절대경로로 바꿔서 해결했다.

```powershell
-Execute 'C:\Program Files\nodejs\node.exe'
```

### PowerShell 5.1 은 BOM 없는 .ps1 을 ANSI 로 읽는다

한글 주석이 깨져 파서가 통째로 실패했다(`Unexpected token '???세뿔'`).
`utf8NoBOM` 도 5.1 에는 없다. 파일 앞에 BOM 3바이트를 붙여 해결했다.

```powershell
[IO.File]::WriteAllBytes($f, ([byte[]](0xEF,0xBB,0xBF) + $bytes))
```

1단계에서 겪은 BOM 문제와 방향만 반대다. **`.env` 는 BOM 이 있으면 안 되고,
`.ps1` 은 BOM 이 있어야 한다.**

**① 저장(POST) Origin 검사** — `REQUIRE_ORIGIN_ON_POST`(기본 켬)
브라우저는 교차 출처 POST 에 Origin 을 반드시 붙인다. 우리 화면은 통과하고
Origin 없이 던지는 스크립트·curl 은 403 이다.
다만 **Origin 은 브라우저 밖에서 위조할 수 있다.** 진짜 인증은 토큰이고
이것은 그 전까지의 최소 방어선이다. 과장해서 볼 것이 아니다.

**② 저장 전용 요청수 제한** — 10분에 100건(IP 기준)
전체 제한(1분 120건)과 별도다. 학교 한 곳이 공유 IP 뒤에서 키오스크 여러 대를
돌려도 닿지 않고, 쏟아붓기는 막힌다.

### 프론트

**삭제를 DELETE 메서드로** (`results-admin.html`)
GET 으로 지우면 주소만 눌러도, 혹은 브라우저·크롤러가 링크를 미리 읽기만 해도
지워질 수 있다. 서버가 DELETE 를 안 받는 구버전인 경우에만 옛 GET 으로 물러선다.

**키오스크 토큰 주입 통로** (`aipia/test.html`)
현장 기기마다 개발자도구를 열 수는 없다. 주소 한 번만 열면 저장된다.

```
https://yedam.kr/aipia/test.html?settoken=<토큰>
```

저장 직후 주소에서 지운다(뒤로가기 기록·화면 공유에 남지 않게).
`?settoken=` 를 값 없이 열면 해제된다. QR 로 만들어 찍어도 된다.

### 실측 (라이브)

```
저장  Origin 없이          403
저장  Origin evil.example  403
저장  Origin yedam.kr      400 "no id"  ← 앱 로직까지 도달. 실제 저장은 정상
삭제  비번 없이            401
삭제  틀린 비번            401
조회  비번 없이            401

브라우저(yedam.kr) 저장경로   400 "no id"  ← 막히지 않음
토큰 주입   저장 O · 주소에서 제거 O · 헤더에 실림 O
```

### 남은 순서 — 토큰 켜기

**순서를 지켜야 한다. 거꾸로 하면 저장이 전부 막힌다.**

1. 서버에서 토큰 생성
   ```powershell
   -join ((1..32) | ForEach-Object { '{0:x2}' -f (Get-Random -Max 256) })
   ```
2. **키오스크마다** `https://yedam.kr/aipia/test.html?settoken=<토큰>` 을 한 번 연다
3. 전부 끝난 뒤에 `C:\yedam\api\.env` 에 `INGEST_TOKEN=<토큰>` 을 넣고 재시작

2번을 건너뛰고 3번을 하면 그 기기의 검사 결과가 저장되지 않는다.
